# Reusable Mega Navbar

in this workshop, you will practice working with React functional components by building a reusable navbar.

&nbsp;

`Note #1`: React functional components need to start with a **capital letter** because it is a way to differentiate from regular HTML elements.

`Note #2`: The reason why `className` is used instead of `class` is because *class* is a **reserved keyword** in JavaScript. And so, React uses `className` as a way to apply classes to elements.

`Note #3`: The `aria-expanded` attribute communicates to screen reader users that the button triggers an **expandable submenu**.
